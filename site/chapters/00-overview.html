第0章

講座の全体像

この講座では、C++講座で作ったLEDクラスやSensorクラスの考え方をそのまま使い、固定翼機を自動で旋回させるフライトコントローラを自作します。この章では、完成したときのシステムの形と、各章がその中のどこを作るのかを先に見ておきます。

この講座のゴール

最終的な目標は、全日本学生室内飛行ロボットコンテスト統合部門の自動系サブミッション（自動水平旋回・自動8の字飛行・自動上昇旋回）を、自作のフライトコントローラで達成することです。そのために、次のことができるようになるのを目指します。

  • サーボとESCに正しい信号を出し、受信機からの信号を読む
  • I2C・SPI・UARTでセンサから値を読み、較正してフィルタを通す
  • ジャイロ・加速度・気圧・距離の値から、姿勢と高度を推定する
  • カスケードPIDで姿勢を制御し、その上に旋回と高度の指令を作る
  • 手動飛行中に自動へ切り替え、いつでも安全に手動へ戻せるようにする
  • 飛行ログを読み、ゲインや設定値を根拠をもって調整する

要求の細かい根拠は大会ルールと要求仕様にまとめています。ルールは毎年改訂されるので、ルールに依存する内容はそのページに集めてあります。

前提とする知識

  • C++講座の内容：クラス、.hと.cppの分割、カプセル化、継承とvirtual、enum class
  • 大学初年次の線形代数（行列の積・転置・逆行列）と微積分

確率・統計（正規分布、分散、共分散）は、カルマンフィルタを扱う第10章で必要な分だけ説明します。

自動操縦システムの全体像

完成したフライトコントローラの中では、次の図のように信号が流れます。図の右上から右下、左下へと「機体が動く → センサが測る → 状態を推定する」の流れがあり、推定した値が上の段の制御へ戻ってきます。

上の段の制御は、内側から順に作ります。いちばん内側の角速度制御はジャイロの値を直接使い、機体の回転の速さを指令どおりにします。その外側の姿勢制御は、推定した姿勢（バンク角やピッチ角）を指令どおりにするために、角速度の指令を作ります。さらに外側の誘導は「右に旋回しながら高度2mを保つ」といった目標から、姿勢の指令を作ります。このように制御を何段も重ねる構成がカスケード制御です。

手動飛行の中に自動飛行がある

統合部門では、離陸・物資の投下・着陸は操縦者が行い、自動系サブミッションの間だけ機体が自律飛行（ハンズオフ飛行）をします。つまり、このフライトコントローラは「手動で飛んでいる最中に自動を開始し、終わったら、あるいは危なくなったら、すぐに手動へ戻す」ことが前提になります。

この切り替えは見た目以上に難しい部分です。自動を開始した瞬間に舵がはね上がらないこと、操縦者がスティックに触れたら即座に手動へ戻ること、電波が切れたら確実にモータを止めることを、第5章と第14章で扱います。

C++講座との対応

「手動」「自動旋回中」「上昇中」といった飛行の状態は、C++講座第9回のenum classとswitchでそのまま書けます。モード管理は、講座の最終課題のRobotStateを発展させたものだと考えてください。

開発環境

開発環境はC++講座と同じものを使います。

  • Visual Studio Code と PlatformIO
  • Arduinoフレームワーク（setup()とloop()）
  • ESP32
  • Git と GitHub

センサは、講座の例として次のような一般的な部品を想定します。実際に使う部品が決まったら、そちらに合わせて読み替えてください。

  • IMU（ジャイロと加速度）：MPU-6050、ICM-42688-P など
  • 気圧センサ：BMP280、DPS310 など
  • 距離センサ（下向き）：VL53L1X などのToFセンサ

また、ロジックアナライザかオシロスコープが1台あると、第4〜6章で信号を目で確かめられるので、理解がずっと速くなります。

安全について

安全

  • ESCとモータをつないで作業するときは、必ずプロペラを外します。プログラムの書き込み直後や電源投入時に、意図せずモータが回ることがあります。
  • 飛行させるときは、操縦者と補助者はゴーグル（眼鏡でも可）を着けます。大会では義務で、練習でも着用が推奨されています。
  • 受信機のフェイルセーフ（電波が切れたらスロットルを切る設定）は、飛行前に毎回確かめます。
  • LiPoバッテリーは、過放電・過充電・物理的な損傷で発火することがあります。充電中はそばを離れないでください。
