第4章

PWM出力：サーボとESC

フライトコントローラが計算した結果は、最後にサーボとESCへの信号になって初めて機体を動かします。この章では、その信号の形を理解し、ESP32で正確に出力するクラスを作ります。

この章の目的

  • RC用PWM信号の周期とパルス幅を説明できる
  • パルス幅とduty比を相互に計算できる
  • ESP32のLEDCで、指定したパルス幅の信号を出せる
  • サーボとESCをクラスとして実装し、危険な値を出さないようにできる

RC用のPWM信号

ラジコンのサーボやESCへの信号は、一定の周期でくり返すパルスです。情報を運んでいるのはパルスの幅で、一般的なサーボでは周期20ms（50Hz）、パルス幅はおよそ1000〜2000µs、中立が1500µsです。

周期のうちHIGHになっている割合をduty比と呼びます。

D = ton T

中立の1500µsなら、D=1500/20000=0.075、つまり7.5%です。1000〜2000µsの範囲はduty比でいえば5〜10%にあたり、周期全体のうち意味のある部分はわずか5%しかありません。このことは、あとで出力の分解能を考えるときに効いてきます。

duty比ではなくパルス幅で考える

サーボやESCが読み取っているのはパルス幅そのものです。周期を変えると、同じduty比でもパルス幅が変わってしまいます。たとえばduty比7.5%は、50Hzなら1500µsですが、100Hzなら750µsで、サーボの範囲外です。そのため、プログラムの中ではパルス幅をµs単位で指定し、duty比への換算は出力の最後の段だけで行うようにします。

なお、この講座で「サーボのPWM」「ESCのPWM」と言うときは、このパルス幅で情報を送る信号を指します。モータドライバでモータの電圧を変えるPWM（duty比そのものが意味を持つもの）とは、同じPWMという名前でも使い方が違います。

サーボとESC

信号の形は同じでも、サーボとESCではパルス幅の意味と扱い方が違います。

サーボESC
パルス幅の意味目標の角度スロットル（モータ出力の目安）
基準の値中立（1500µs付近）最小（モータ停止）
起動時に出す値中立最小
必要な調整中立のずれ、両端の範囲、回転方向の反転スロットル範囲の校正
値を誤ったときの危険舵面が機械的な端に当たり、サーボが焼けるプロペラが回り出す

サーボの動く範囲は機種によって違い、500〜2500µsまで動くものもあります。機体に取り付けたあとは、舵面やリンケージが端に当たらない範囲だけを使うように、両端の値を機体ごとに決めます。

補足：更新の速さ

50Hzの信号では、サーボへの指令は20msに1回しか更新されません。制御ループをそれより速く回しても、サーボに届くのは直前に書き込んだ値だけです。デジタルサーボの多くはもっと短い周期の信号を受け付けますが、対応する周期は機種によって違い、対応していない周期を入れると動作が不安定になったり故障したりします。周期を上げるときは、必ずデータシートで確かめてください。

補足：小型機のモータ駆動

ESCの多くは、受信機やサーボに5Vを供給するBEC（電源回路）を内蔵しています。一方、ごく小型の室内機では、ブラシモータをトランジスタ（FET）で直接駆動することもあります。その場合のPWMはモータの電圧を決めるduty比そのもので、周波数も数kHz以上と、この章で扱う信号とは別物になります。

ESP32のLEDCで信号を作る

ESP32には、PWM信号をハードウェアで作るLEDCという機能があります。LEDCは、内部のカウンタが一定の速さで0から2n−1まで数えることをくり返し、カウンタの値が設定値より小さい間だけ出力をHIGHにします。nは分解能（ビット数）です。

カウンタが1周する時間が周期Tなので、パルス幅tonを出すための設定値（カウント値）と、1カウントあたりの時間は次のようになります。

count = round⁡ ( ton T ⋅ 2n ) , Δt = T 2n

50Hz、14ビットの場合を計算すると次の表になります。1カウントは約1.22µsで、1000〜2000µsの範囲を約820段階で出せます。

パルス幅t_on / Tカウント値
1000µs0.050819
1500µs0.0751229
2000µs0.1001638

分解能はいくらでも上げられるわけではありません。カウンタを数えるクロックの周波数をfclkとすると、周波数と分解能は

f ⋅ 2n ≤ fclk

を満たす必要があり、さらにnの上限はESP32の型番によって違います（たとえばESP32-S3では14ビットまで）。この講座では、どの型番でも使える14ビットを標準にします。

補足：Arduino-ESP32のバージョンによる違い

この章のコードは、Arduino-ESP32コア3.x系の書き方（ピン番号で指定するledcAttach()とledcWrite()）を使っています。2.x系では、先にチャンネルをledcSetup(チャンネル, 周波数, ビット数)で設定し、ledcAttachPin(ピン, チャンネル)でピンに割り当て、ledcWrite(チャンネル, 値)で書き込みます。自分の環境のバージョンは、PlatformIOのプラットフォーム設定で確認してください。

クラスとして実装する

出力まわりは、役割の違う3つのクラスに分けます。

  • PwmChannel：LEDCを直接扱い、「何µsのパルスを出すか」だけを知っている
  • ServoOutput：−1〜+1の指令を、そのサーボの中立・両端・向きに合わせたパルス幅に変換する
  • EscOutput：0〜1のスロットル指令をパルス幅に変換し、アームしていない間は必ず停止の値を出す

制御のコード（第11章以降のPID）は−1〜+1や0〜1の値だけを扱い、µsもLEDCも知らなくて済みます。サーボを交換したり、マイコンを変えたりしても、直すのはこれらのクラスの中だけです。

C++講座との対応

C++講座第14回の「1クラス1責務」と、第8回のカプセル化をそのまま使っています。中立や両端の値をprivateにし、外からはsetCommand()を通してしか出力を変えられないようにすることで、範囲外の値が出ることを防いでいます。

PwmChannel

+ 0.5fしてから整数に変換しているのは、切り捨てではなく四捨五入にするためです。

C++講座では扱わなかった書き方

  • static_cast<uint32_t>(値)は、値をuint32_t型に変換することを明示する書き方です。(uint32_t)値というCの書き方より意図がはっきりし、危険な変換をコンパイラが見つけやすくなります。
  • 1UL << resolutionBitsは、1を左にresolutionBitsビットずらす計算で、2nと同じ値になります。ULは「unsigned longの1」という意味です。
  • std::isnan()は<cmath>にある関数で、値がNaNかどうかを調べます。std::は第5回の名前空間です。

ServoOutput

ServoOutputはPwmChannelをメンバとして持っています。継承ではなく、このように別のクラスを部品として持つ形をコンポジションと呼びます。「ServoOutputはPwmChannelである」とは言えない（is-aの関係ではない）ので、継承は使いません。

EscOutput

サーボでは異常な指令を中立として扱いましたが、ESCでは停止として扱います。異常が起きたときにどちらへ倒すのが安全かは、出力先によって違います。

動かしてみる

サーボをゆっくり往復させるだけの確認用プログラムです。ESCは初期化して停止の値を出すだけで、アームはしません。

補足：ピンの選び方

ESP32のピンの中には、起動時の動作モードを決める「ストラッピングピン」や、内蔵フラッシュに使われていて使えないピンがあり、どれが該当するかは型番によって違います。PWM出力に使うピンは、使用する型番のデータシートで確かめてから決めてください。

ミキサ：制御の出力を舵へ割り振る

普通の尾翼を持つ機体なら、ロール・ピッチ・ヨーの制御出力をそれぞれエルロン・エレベータ・ラダーへそのまま渡せば済みます。しかし、主翼の後縁の舵だけでロールとピッチの両方を操作するエレボン機（全翼機など）では、1つの舵に2つの制御出力を混ぜる必要があります。左右のエレボンの指令をδL、δR、ピッチとロールの制御出力をe、aとすると、基本形は次のとおりです。

δL=e+a , δR=e−a

符号はサーボの取り付け向きによって変わるので、ServoOutputのreversedで合わせます。また、eとaがどちらも大きいと合計が±1を超えるので、どちらを優先して残すかを決めておく必要があります。この扱いは、制御ループと合わせて第12章で詳しく扱います。

ESCを安全に扱う

多くのESCは、電源を入れた直後に最小スロットルの信号をしばらく受け取らないと、モータを回せる状態（アーム状態）になりません。電源を入れたときにスロットルが上がっていて、いきなりプロペラが回るのを防ぐための仕組みです。EscOutput::begin()で最初に最小値を出しているのはこのためです。

また、ESCは「どのパルス幅を停止、どのパルス幅を最大とするか」を覚えさせる校正が必要なことがあります。手順はESCによって違いますが、最大の信号を出したまま電源を入れ、合図の音が鳴ったら最小の信号に下げる、という形が多いです。必ず自分のESCの説明書に従ってください。

安全

ESCの校正や、ESCにつないだ状態でのプログラムの書き込み・動作確認は、必ずプロペラを外して行います。校正では意図的に最大スロットルの信号を出すので、手順を間違えるとモータが全開で回ります。

大会ルール：フェイルセーフとの関係

ルールでは、電波が切れたら受信機側でスロットルを切ることが求められています。受信機のスロットル出力をESCに直接つなぐなら、受信機のフェイルセーフ設定だけで済みます。しかし、フライトコントローラがESCを駆動する構成では、受信機が「スロットル最小」を出しても、フライトコントローラがそれを読んでEscOutputに反映しなければモータは止まりません。受信機のフェイルセーフを確実にESCまで届ける方法は、第5章と第14章で扱います。

実機で確かめる

  1. ロジックアナライザかオシロスコープで出力ピンを測り、周期が20ms、パルス幅が指令どおり（中立なら1500µs）になっているかを確かめます。
  2. サーボはホーン（腕）を外した状態で中立の位置を確かめてから取り付けます。
  3. 舵面につないだら、指令を少しずつ±1に近づけ、舵面やリンケージが端に当たらない範囲でminUsとmaxUsを決めます。
  4. プロペラを外した状態で、ESCがアームし、スロットルに応じて回転が変わることを確かめます。

演習

  1. 50Hz・14ビットのとき、1100µsと1900µsのカウント値を求めよ。
  2. 333Hz・14ビットのとき、1500µsのカウント値と、1カウントあたりの時間を求めよ。
  3. ServoOutputに、中立のずれを補正するsetTrim(float trimUs)を追加せよ。トリムを加えた結果がminUs〜maxUsを超えないようにすること。
  4. ServoOutputのコンストラクタで固定している「50Hz・14ビット」を、引数で指定できるように変更せよ。周波数と分解能がf⋅2n≤fclkを満たさない場合はどうするのがよいか、考えて実装せよ。
  5. 制御ループを500Hzで回し、サーボへの信号が50Hzの場合、制御ループの1回ごとにsetCommand()を呼ぶと何が起きるか。サーボに実際に届く指令はどれか、説明せよ。
演習1・2の答え

1．1100µsは1100/20000⋅16384=901.12なので901、1900µsは1556.48なので1556。

2．周期は1/333秒＝約3003µs。カウント値は1500/3003⋅16384≈8183.8なので8184、1カウントあたりは3003/16384≈0.18µs。周期が短くなった分、同じ14ビットでも細かく出力できる。
